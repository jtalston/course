The user is about to be pulled away and wants to save their place. Extra note: **$ARGUMENTS**

Write a breadcrumb to `.adhd/breadcrumb.md` (overwrite it — only the latest matters) that lets them resume with zero re-derivation. Capture from the current conversation and working state:

1. **What I was doing** — the task in one sentence.
2. **The exact next step** — the single action they were about to take. Be specific: file, function, command, line of thinking.
3. **Open loops** — anything half-done, any decision left hanging, any command running.
4. **Don't-forget** — the one detail that would be expensive to reconstruct (a value, a gotcha, why they ruled something out).
5. **Their note** — include `$ARGUMENTS` verbatim if provided.

Stamp it with the current date. Keep it to a handful of lines — a breadcrumb, not a report. Then tell them it's saved and they're free to go. Don't keep working.
