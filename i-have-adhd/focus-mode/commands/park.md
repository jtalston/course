Mid-focus, a new idea or worry showed up and is competing for attention: **$ARGUMENTS**

The instinct is to chase it now. The fix is to prove to the brain it won't be lost, then return.

1. Write the thought into a running parking lot at `.adhd/parking-lot.md` (create the file and folder if needed). Append it as a bullet with a short, faithful restatement — don't expand it into a project, just capture it so it's safe.
2. In one sentence, judge honestly: is this actually urgent enough to interrupt the current block, or can it wait? Default to "it can wait."
3. If it can wait, tell them it's parked and point them straight back to what they were doing. Do not start working on the parked item.
4. If it's genuinely urgent (something breaking, a real deadline), say so directly and let them decide to switch.

Short and reassuring. The whole point is: it's written down, you can stop holding it.
