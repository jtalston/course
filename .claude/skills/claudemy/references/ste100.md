# ASD-STE100 Simplified Technical English: how lessons follow it

Use this when `sources.json` has `"style": "ste100"`. It replaces the casual voice rules in `writer-brief.md` (contractions, reactions, audio tags). Everything else in the writer brief stays.

ASD-STE100 is a controlled language: a set of writing rules plus a dictionary of approved words, each with one meaning. This file applies the writing rules. The official dictionary is not part of this skill, so word choice follows its principles (common words, one meaning per word, one word per meaning) and is not certified conformance. Say so if anyone asks.

## Writing rules
**Words**
- Use simple, common words. Use one word for one thing and keep it: if you say "branch" do not change to "line of work".
- Technical names are allowed: Git commands, flags, file names, product names (reflog, worktree, `git bisect run`).
- Do not use "-ing" words as nouns or adjectives ("the merging of"). Write "when you merge".
- Do not use phrasal verbs when a single verb exists: "start", not "kick off"; "find", not "figure out".
- No slang, idioms, jokes or metaphors that need cultural knowledge.

**Sentences**
- Instructions (procedures, Try it steps): 20 words maximum. One instruction per sentence. Use the imperative: "Run git reflog."
- Explanations (descriptive text): 25 words maximum. One topic per sentence.
- Use the active voice. Use the simple present, simple past or future.
- Keep articles ("the", "a"). Do not drop words to make a sentence shorter.
- Put the condition first: "If the remote changed, Git stops the push."

**Paragraphs and lists**
- Six sentences maximum in a paragraph, one topic per paragraph.
- Use vertical lists for steps. Put a warning before the step it applies to.

## Scripts in STE
- Two speakers stay. Speaker A explains. Speaker B asks the question the listener has, or repeats the key point in different simple words.
- No audio tags, no reactions such as "oof" or "wow", no contractions.
- 280 to 350 words, as usual. Short sentences make the pace calm, so the 1.25x speed stays clear.
- The shape stays: the problem, the idea, how many sources agree and who disagrees, one real example from a page, the thing to try, one line on what changes.
- Say commands as words: "git reflog", "reset with the hard option". No flags with dashes in speech.

## Cards in STE
- All prose obeys the sentence limits above. Try it steps are instructions: 20 words maximum each.
- Commands go in code formatting, exactly as typed.

## What the checker enforces (`check_lessons.py` in STE mode)
- Fail: a script sentence over 25 words; a Try it sentence over 20 words; a card sentence over 25 words; audio tags; contractions.
- Warn: "-ing" words outside an allow list, and likely passive voice (is/are/was/were + past participle). A human decides.
